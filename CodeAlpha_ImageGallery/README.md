🖼️ Interactive Image Gallery - CodeAlpha Task 2A responsive, modern image gallery web application built using HTML5, CSS3, and JavaScript. Developed as part of the CodeAlpha Web Development Internship.✨ FeaturesResponsive Grid Layout: Clean multi-column gallery layout built with CSS Grid and Flexbox that seamlessly adapts across mobile, tablet, and desktop screens.Category Filtering: Filter gallery items by tags/categories (e.g., All, Nature, Architecture, Travel, Animals) with instant transition animations.Interactive Lightbox Modal:Click any photo to view it in full-resolution modal preview.Captions, titles, and image details displayed cleanly.Next / Previous Navigation:On-screen slider navigation arrows (❮ Previous, ❯ Next).Keyboard arrow navigation (← Left / → Right) and Esc to close.Smooth Transitions & Hover Effects: Polished image zoom hover states, smooth fade-in overlays, and backdrop blur.🛠️ Tech StackHTML5: Semantic markup for the gallery layout, filter controls, and lightbox dialog.CSS3: CSS Grid, Flexbox, media queries, hover transitions, and glassmorphism lightbox overlay.JavaScript (ES6+): Dynamic image filtering, DOM manipulation, modal controls, and keyboard event listeners.📁 Project StructureCodeAlpha_ImageGallery/
├── index.html        # Main HTML markup and gallery structure
├── style.css         # Styling, responsive grid, animations & modal CSS
├── script.js         # Filter logic, lightbox viewer & navigation controls
└── README.md         # Project documentation
