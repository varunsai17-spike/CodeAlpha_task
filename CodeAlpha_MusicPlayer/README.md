🎵 Spotify Desktop Music Player - CodeAlpha TaskA modern, responsive, Windows desktop-inspired Spotify Music Player web application built with HTML5, Tailwind CSS, JavaScript (ES6+), and Web Audio API. Developed as part of the CodeAlpha Web Development Internship.✨ FeaturesDesktop Application Interface:Windows-style title bar with minimize/maximize/close window controls, back/forward history buttons, and profile pill (varun with PREMIUM tag).3-panel layout: Left Library Navigation, Central Dynamic Viewport, and Collapsible Right "Now Playing" View.Authentic Spotify Home & Playlists:Quick-access 2-column tiles (Liked Songs, Romantic Harris, phonk, Trending Tamil, etc.).Browse sections: Jump back in, Recommended Stations, and Trending Regional Hits.Interactive playlist detail views with dynamic gradient banners and track listings.Dual Audio Engine:HTML5 Audio Streaming: Streams high-fidelity audio tracks.Web Audio API Synth Fallback: Seamless synthesized melodic chord and bass progressions that activate automatically if network streaming or CORS restrictions occur.Local Audio File Player: "Open MP3" button allows users to load and play audio files directly from their local drive.Full Transport & Audio Controls:Seekable timeline scrubber with elapsed and total duration timestamps.Play / Pause, Next (▶|), Previous (|◀), and Repeat toggles.Responsive volume slider with one-click Mute / Unmute.Keyboard Shortcuts:Space: Play / Pause toggle→ (Right Arrow): Next track← (Left Arrow): Previous trackInteractive Search & Filter:Live search bar to filter playlists, tracks, and artists in real-time.🛠️ Tech StackHTML5: Semantic application structure and <audio> streaming element.Tailwind CSS: Modern desktop layout, Spotify dark palette, flex/grid systems, and hover animations.JavaScript (ES6+): Playlist state management, audio event synchronization, timeline scrubbing, and DOM manipulation.Web Audio API: Real-time synthesizer oscillator fallback for offline or restricted environments.📁 Project StructureCodeAlpha_MusicPlayer/
